# Task 9.4: Responsive Design Review

## Description

Review and fix responsive design for mobile, tablet, and desktop.

## Priority
🟡 High — User experience

## Dependencies
- All Phase 8 tasks complete

## Steps

### Step 1: Test on different screen sizes
1. Mobile (375px): Check all pages
2. Tablet (768px): Check all pages
3. Desktop (1024px+): Check all pages

### Step 2: Fix issues
1. Sidebar: collapse to hamburger menu on mobile
2. Cards: single column on mobile, grid on desktop
3. Forms: full width on mobile
4. Tables: horizontal scroll on mobile

### Step 3: Add responsive utilities
1. Use Tailwind responsive prefixes: `sm:`, `md:`, `lg:`
2. Test navigation on all breakpoints

## Acceptance Criteria

- [ ] Mobile: sidebar collapses, single column layout
- [ ] Tablet: 2-column grid
- [ ] Desktop: full layout with sidebar
- [ ] Forms work on all screen sizes
- [ ] No horizontal scrolling on mobile
